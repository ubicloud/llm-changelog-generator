## Managed PostgreSQL

### Storage Auto-Scaling

Ubicloud Managed PostgreSQL now automatically scales up storage when disk usage gets high. When your database reaches critical thresholds, the system resizes storage without manual intervention — keeping your database available even during unexpected data growth. Hobby-tier databases that hit their storage ceiling are automatically upgraded to the standard tier so they can continue scaling.

<PrList ids={[4730, 4754, 4755, 4783, 4798]} />

### Hobby Tier

Burstable PostgreSQL instances have been renamed to "hobby" to better signal that these instances are intended for development, experimentation, and non-production workloads.

<PrList ids={[4738, 4759]} />

### Failover Testing with /recycle

You can now trigger a failover on your PostgreSQL instance via the new `/recycle` API endpoint. This lets you test your application's resilience to failovers in a controlled way.

<PrList ids={[4703]} />

### Transaction-Mode PgBouncer by Default

New PostgreSQL instances now default to PgBouncer's `transaction` pool mode, which allows better connection reuse. Existing instances are unaffected — their pool mode has been preserved as `session`.

<PrList ids={[4769]} />

### Restart Requirement Indicators for Config Parameters

The PostgreSQL configuration UI now shows which parameters require a database restart to take effect. This helps you plan configuration changes and understand when a restart is needed.

### IPv6 (AAAA) Records for Older Databases

A new option in the web console lets you add AAAA DNS records to PostgreSQL databases created before IPv6 support was available, making it easy to enable IPv6 connectivity on older instances.

### Replication via the postgres User

You can now set up logical or physical replication connections using the `postgres` user, simplifying replication configuration for advanced use cases.

## Ubicloud Kubernetes

### Mesh Connectivity Monitoring

Kubernetes clusters now include built-in mesh network connectivity monitoring. The CSI node plugin periodically checks TCP connectivity between pods across nodes and to external endpoints, enabling faster detection and alerting of network isolation issues.

<PrList ids={[4702, 4704, 4720, 4722, 4742, 4766, 4828]} />

### Improved Node Lifecycle Reliability

Several improvements make node upgrades and scaling more reliable: firewall rules now persist across node reboots, CSI data migrations retry on failure instead of getting stuck, and kubelet certificate approval is properly sequenced during node provisioning.
